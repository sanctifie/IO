## Étape 1 — Le serveur principal

:::warn « Open all ports »
Le tutoriel d'origine dit d'ouvrir **tous** les ports dans le Security Group. Ne le fais pas : ouvre uniquement les ports listés, et seulement depuis ton IP. :::

## Étape 2 — Jenkins, Docker, SonarQube, Trivy

```bash

```

1. **Jenkins** : recette de l'annexe A.3 (Java 21 + dépôt Jenkins). *(Le tutoriel installe Temurin 17 depuis le dépôt Adoptium : c'est aussi valable.)*
2. **Docker** :

```bash
sudo apt install -y docker.io
sudo usermod -aG docker ubuntu
sudo usermod -aG docker jenkins       # Jenkins doit pouvoir lancer docker
sudo systemctl restart jenkins
newgrp docker                          # appliquer le groupe dans ta session actuelle
```

:::danger Pas de `chmod 777 /var/run/docker.sock`
Le tutoriel fait `sudo chmod 777 /var/run/docker.sock` : **n'importe quel utilisateur ou processus** de la machine devient alors root via Docker, et le réglage disparaît au redémarrage de Docker. L'ajout de `jenkins` au groupe `docker` + redémarrage de Jenkins est la bonne méthode.
:::

3. **SonarQube** en conteneur :


*(Le tag `sonarqube:lts-community` du tutoriel est l'ancien nom ; `community` est la version Community Build actuelle. Le volume garde les données si le conteneur est recréé.)*

## Étape 3 — La clé d'API TMDB

L'application affiche des films grâce à **The Movie Database** : crée un compte sur `themoviedb.org` → profil → *Settings → API → Create → Developer* → accepte les conditions → remplis le formulaire → copie la **clé API (v3)**.

:::why Pourquoi passer la clé au moment du build ?
C'est une application **front-end** (React compilé par Vite) : le code s'exécute dans le navigateur de l'utilisateur. La clé est injectée **à la compilation** (`ARG TMDB_V3_API_KEY` → `ENV VITE_APP_TMDB_V3_API_KEY` dans le Dockerfile) et se retrouve **dans le JavaScript envoyé aux navigateurs**. Elle n'est donc **pas secrète** pour les visiteurs : c'est acceptable pour une clé TMDB gratuite, jamais pour une vraie clé sensible (qui doit rester côté serveur, derrière une API).
:::

## Étape 5 — Surveiller Jenkins avec Prometheus

1. Jenkins → *Plugins* → installe **Prometheus metrics**. Il expose les métriques sur `http://<IP_JENKINS>:8080/prometheus` (*Manage Jenkins → System → Prometheus* pour les options).
2. Sur le serveur de monitoring, ajoute la cible dans `/etc/prometheus/prometheus.yml` :

```yaml
  - job_name: jenkins
    metrics_path: /prometheus
    static_configs:
      - targets: ['<IP_PRIVEE_JENKINS>:8080']
```

```bash
promtool check config /etc/prometheus/prometheus.yml     # toujours valider avant de recharger
curl -X POST http://localhost:9090/-/reload               # rechargement à chaud (--web.enable-lifecycle)
```

3. Le Security Group du serveur Jenkins doit autoriser **8080 depuis le serveur de monitoring**.
4. Grafana → import du tableau **9964** (Jenkins performance and health).

## Étape 8 — Le pipeline

Fork `github.com/Aj7Ay/Netflix-clone` sur ton GitHub. Jenkins → *New Item* `netflix` → **Pipeline** → script :

```groovy
pipeline {
    agent any
    tools {
        jdk 'jdk17'
        nodejs 'node16'
    }
    environment {
        SCANNER_HOME = tool 'sonar-scanner'
        IMAGE = '<toi-dockerhub>/netflix'
    }
    stages {
        stage('Clean workspace') { steps { cleanWs() } }

        stage('Checkout') {
            steps { git branch: 'main', url: 'https://github.com/<toi>/Netflix-clone.git' }
        }

        stage('Analyse SonarQube') {
            steps {
                withSonarQubeEnv('sonar-server') {
                    sh '$SCANNER_HOME/bin/sonar-scanner -Dsonar.projectName=Netflix -Dsonar.projectKey=Netflix'
                }
            }
        }

        stage('Quality Gate') {
            steps {
                script { waitForQualityGate abortPipeline: false, credentialsId: 'Sonar-token' }
            }
        }

        stage('Dépendances') { steps { sh 'npm install' } }

        stage('OWASP Dependency-Check') {
            steps {
                withCredentials([string(credentialsId: 'nvd-api-key', variable: 'NVD_KEY')]) {
                    dependencyCheck additionalArguments: "--scan ./ --disableYarnAudit --disableNodeAudit --nvdApiKey ${NVD_KEY}",
                                    odcInstallation: 'DP-Check'
                }
                dependencyCheckPublisher pattern: '**/dependency-check-report.xml'
            }
        }

        stage('Trivy FS') { steps { sh 'trivy fs . > trivyfs.txt' } }

        stage('Build & push Docker') {
            steps {
                withCredentials([string(credentialsId: 'tmdb-api-key', variable: 'TMDB')]) {
                    script {
                        withDockerRegistry(credentialsId: 'docker', toolName: 'docker') {
                            sh '''
                              docker build --build-arg TMDB_V3_API_KEY=$TMDB -t $IMAGE:$BUILD_NUMBER -t $IMAGE:latest .
                              docker push $IMAGE:$BUILD_NUMBER
                              docker push $IMAGE:latest
                            '''
                        }
                    }
                }
            }
        }

        stage('Trivy image') { steps { sh 'trivy image $IMAGE:$BUILD_NUMBER > trivyimage.txt' } }

        stage('Déployer en conteneur') {
            steps {
                sh '''
                  docker rm -f netflix || true
                  docker run -d --name netflix -p 8081:80 $IMAGE:$BUILD_NUMBER
                '''
            }
        }

        // Étape 9 : décommenter une fois le cluster Kubernetes prêt
        // stage('Déployer sur Kubernetes') {
        //     steps {
        //         dir('Kubernetes') {
        //             withKubeConfig(credentialsId: 'k8s') {
        //                 sh 'kubectl apply -f deployment.yml -f service.yml'
        //             }
        //         }
        //     }
        // }
    }
    post {
        always {
            emailext attachLog: true,
                subject: "${currentBuild.result} : ${env.JOB_NAME} #${env.BUILD_NUMBER}",
                body: "Projet : ${env.JOB_NAME}<br/>Build : ${env.BUILD_NUMBER}<br/>URL : ${env.BUILD_URL}",
                to: 'ton.compte@gmail.com',
                attachmentsPattern: 'trivyfs.txt,trivyimage.txt'
        }
    }
}
```

Ajoute aussi la clé TMDB en credential *Secret text* ID **`tmdb-api-key`**.

## Dépannage

:::fix
- **`docker: permission denied` dans Jenkins** : `jenkins` pas dans le groupe docker, ou Jenkins pas redémarré.
- **SonarQube s'arrête au démarrage** : `docker logs sonar` → `vm.max_map_count` (étape 2) ou mémoire insuffisante.
- **Dependency-Check très long ou en erreur 403** : clé NVD absente.
- **`npm install` échoue** (versions de Node) : le projet date de 2023 ; Node 16 fonctionne, Node 20 aussi la plupart du temps. En cas d'erreur, garde `node16` comme dans l'original.
- **Pas d'affiches de films** : clé TMDB absente ou invalide au moment du build.
- **E-mail non reçu** : mot de passe d'application (pas ton mot de passe Gmail), port 465 + SSL, ou dossier spam.
- **`withKubeConfig` : `Unable to connect to the server`** : adresse du master injoignable depuis Jenkins, ou port 6443 fermé.
- **Pods `ImagePullBackOff`** : nom d'image du `deployment.yml` non modifié.
:::
